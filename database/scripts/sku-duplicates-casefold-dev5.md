## Rekomendasi strategi

1. **SKU cuma beda huruf besar/kecil** → **jangan remap stok seperti satuan**. Lebih mudah:
   - Tahan varian yang **punya stok / history** (biasanya lokal / id lebih kecil)
   - Update SKU-nya ke ejaan PMO (kanonik)
   - Isi `products.ref_product_id` dari produk PMO
   - Nonaktifkan produk/varian PMO duplikat yang stoknya 0
   - Remap baris SO yang sudah menunjuk varian PMO kosong → varian yang di-keep (sedikit UPDATE `sales_order_details.product_variant_id`)
2. **Nama mirip / SKU beda total** (contoh DOSAAH1500ML vs Aahk1500ml) → sama pola di atas, tapi matching manual/fuzzy; **wajib** remap SO + nonaktifkan duplikat.
3. Remap massal semua FK seperti satuan **hanya** kalau mau hapus product_variant_id lama — lebih berat, biasanya tidak perlu.
