# Armada

## Tujuan
Mengelola data armada. Secara operasional Armada dan customer biasa seharusnya diperlakukan sama (menu terpisah ada karena perubahan fitur lama).

## Siapa yang bisa
Modul **Armada**: view / create / edit / delete.

## Alur
Tambah, ubah, dan hapus data di menu Armada. Hapus = data dinonaktifkan, tidak hilang permanen.
