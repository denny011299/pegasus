# Daftar Produk

## Tujuan
Mendaftarkan produk jadi beserta varian dan relasi satuan.

## Siapa yang bisa
Modul **Daftar Produk**: view / create / edit / delete.

## Alur
1. Buka Produk → Daftar Produk.
2. Buat produk (nama, kategori, dll.).
3. Kelola varian produk dan stok per satuan.
4. Hapus = data dinonaktifkan, tidak hilang permanen.

## Aturan bisnis
Produk wajib punya BOM aktif sebelum diproduksi. Untuk dijual, BOM tidak wajib.

## Status
Produk/varian: Aktif atau Dihapus.
