# Kategori

## Tujuan
Mengelola daftar kategori produk jadi (bukan bahan mentah).

## Siapa yang bisa
Modul **Kategori**: view / create / edit / delete sesuai peran.

## Alur
1. Buka menu Master → Kategori.
2. Tambah kategori (nama).
3. Edit atau hapus (soft delete) bila perlu.

## Status
- aktif
- dihapus

## Validasi
Nama wajib diisi di form (validasi frontend).
