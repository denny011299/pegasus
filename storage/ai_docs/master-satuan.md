# Satuan

## Tujuan
Mengelola satuan hitung (pcs, kg, dus, dll.) untuk produk dan bahan.

## Siapa yang bisa
Modul **Satuan**: view / create / edit / delete. Siapa pun yang punya hak akses modul ini boleh mengubah satuan/konversi. Tidak ada proses wajib di luar sistem.

## Alur
1. Buka Master → Satuan.
2. Tambah / edit / hapus satuan.

## Status
Aktif atau Dihapus.
