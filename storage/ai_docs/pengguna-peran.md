# Pengguna & Peran

## Tujuan
Mengelola akun staf dan hak akses per modul.

## Siapa yang bisa
- **Pengguna**: view / create / edit / delete
- **Peran & Perizinan**: view / create / edit / delete

## Alur
1. Buat Role dengan daftar modul + ability (lihat, tambah, ubah, hapus, aksi lain seperti ACC/tolak).
2. Assign role ke staff.
3. Satu orang = satu peran (tidak multi-role).
4. Peran Super Admin bisa mengakses semua menu.
