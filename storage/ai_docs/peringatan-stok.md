# Peringatan Stok (Produk & Bahan)

## Tujuan
Menetapkan ambang batas stok minimum agar muncul peringatan di aplikasi/dashboard. Tidak ada notifikasi WA/email.

## Siapa yang bisa
- **Peringatan Stok Produk**
- **Peringatan Stok Bahan Mentah**
Masing-masing: view / create / edit / delete.

## Alur
Atur batas stok minimum per item. Hapus = data dinonaktifkan, tidak hilang permanen.
