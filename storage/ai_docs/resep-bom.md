# Resep Bahan Mentah (BOM)

## Tujuan
Menentukan resep bahan untuk menghasilkan produk.

## Siapa yang bisa
Modul **Resep Bahan Mentah**: view / create / edit / delete.

## Alur
Tambah, ubah, dan hapus resep beserta bahan/qty/satuan. Hapus = data dinonaktifkan, tidak hilang permanen.

## Aturan bisnis
Satu produk hanya boleh punya satu BOM aktif.
