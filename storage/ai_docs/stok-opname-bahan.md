# Stok Opname Bahan Mentah

## Tujuan
Menghitung stok fisik bahan mentah dan menyesuaikan sistem setelah disetujui.

## Siapa yang bisa
Modul **Stok Opname Bahan Mentah**: view / create / edit / delete / others.

## Alur / status
Sama pola dengan opname produk (bisa disimpan sebagai draft; status Menunggu / Disetujui / Ditolak / Dihapus). Pakai **versi terbaru** (lines). Jika ada **stok opname freeze**, hanya satu orang yang input.
